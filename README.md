# FrameKeeper

Working title during development: Polaroid AutoCrop.

Desktop software (macOS + Windows) that finds every instant-film print in a large
flatbed TIFF scan, crops each print without ever cutting into its real scanned
border, exports the image area for colour grading in other software, and puts the
graded image back inside the original border losslessly.

Status: under development. See `docs/PROGRESS.md`.
