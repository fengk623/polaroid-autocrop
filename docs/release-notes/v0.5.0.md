# FrameKeeper 0.5.0

First public build (pre-release: some items still need human verification, see below). Free, offline, for macOS 12+ (universal) and Windows 10/11 x64.
中文说明见下方。

## What it does

- **Finds every instant print in a flatbed scan** — Polaroid 600 / i-Type / SX-70, Polaroid round frame,
  Instax Mini / Square / Wide; 1–12 prints per scan, tilted or touching; 8/16-bit TIFF,
  LZW / ZIP / uncompressed, BigTIFF, with or without ICC profile, 300–1600 DPI. Uncertain prints are flagged
  (red outline, "must review") instead of guessed silently.
- **Edits**: drag corners and edges, type coordinates, snap to edges, round image areas, upright rotation,
  undo/redo, review queue (⌘↩ / Ctrl+Enter = reviewed + next), templates for scanner jigs.
- **Exports the image area** as TIFF, PNG, JPEG or Linear DNG, either pixel-exact crops or perspective-
  corrected; ICC kept or converted; private metadata removed by default.
- **Relinks graded files** (embedded XMP → sidecar → file name → manual) with a content check, and
  **composites them back into the real scanned frame** (frame pixels unchanged) or into a generated frame.
- Projects (`.fkproj`) with relative paths; scans are only ever read.

## Measured (synthetic 24-scan corpus, see TEST-PLAN §4)

0 cut frames, 0 missed visible prints, outer-edge slack median 1.2 px, inner error median 0.1 px, film type
and orientation 100 %. A 1600 DPI 16-bit A4 scan (1.7 GB) is detected in about 18 s with ≈ 320 MB peak memory
on a 2-core VM.

## Known issues found in the owner's testing (2026-10-30)

This build is the frozen baseline for the v1.0 work; each item below has a ticket and will be fixed in a later
pre-release.

- Relinking a graded file fails when it was renamed by the editor, lost the embedded metadata or has no `.fk.json`
  next to it ("No matching print"), and after restarting without saving the project (UX-07).
- "Image only" exports can keep a thin strip of the white frame (≈ 0.1–0.2 mm on a 1200 DPI scan) because the
  detected inner edge lies slightly outside the picture (UX-02).
- Changing "Prints per scan" does not clear an earlier count warning; there is no automatic-count switch (UX-01).
- "Rotate upright" changes only the export orientation; whole-scan rotation is missing (UX-04).
- Same-size graded files are composited without the rotation found by the content check (FK-002); a graded file
  without a profile is not interpreted with the export profile (FK-003).
- "Remove identity" can still copy the creator from the scan's XMP (FK-004).
- Grey MinIsWhite scans show inverted at full resolution (FK-011).
- New/Open/drag-in do not ask to save the current project (FK-001); a damaged project does not offer its backup
  (FK-008).

## Known limitations

- Builds are **not code-signed or notarised** — see docs/INSTALL.md for the first launch.
- A black frame on a black scanner lid cannot be outlined from pixels; such prints are reported as missing
  (count warning). Scan dark frames on a light backing.
- On real scans with a bright lid the outer edge can sit 0.3–1.4 mm outside the paper (never inside).
- Screen colour: on Windows the canvas uses the primary monitor's ICC profile (not per monitor); on macOS the
  system converts from sRGB. Not yet checked with a colorimeter.
- Undo history is not saved with the project; there is no disk thumbnail cache yet.
- Not yet verified by a person: drawing and colour in a real window on macOS/Windows, colour accuracy against
  a reference, an 8 GB machine with a 1.5 GB scan (docs/HUMAN-VERIFICATION.md).

# FrameKeeper 0.5.0（中文）

首个公开版本（预发布：部分项目尚待人工验证，见下文）。免费、离线，支持 macOS 12+（通用二进制）与 Windows 10/11 x64。

- **自动识别扫描件中的每张拍立得**：Polaroid 600 / i-Type / SX-70、Polaroid 圆形画框、Instax Mini / Square / Wide；每张扫描 1–12 张，可倾斜、可贴边；8/16 位 TIFF，LZW / ZIP / 无压缩、BigTIFF，有无 ICC 均可，300–1600 DPI。不确定的结果会标红并要求复核，不会悄悄猜测。
- **编辑**：拖动角点与边、输入坐标、吸附边缘、圆形画面、正向旋转、撤销/重做、复核队列（⌘↩ / Ctrl+Enter = 已复核并下一张）、扫描托架模板。
- **导出画面区域**为 TIFF、PNG、JPEG 或 Linear DNG，可选像素级精确裁切或透视校正；保留或转换 ICC；默认移除隐私元数据。
- **重新关联调色后文件**（内嵌 XMP → 附属文件 → 文件名 → 手动）并做内容校验，然后**合成回真实扫描相框**（相框像素不变），或合成到生成的边框。
- 项目文件（`.fkproj`）使用相对路径；扫描件只读，永不修改。

**用户实测发现的已知问题（2026-10-30，均已登记工单，将在后续预发布修复）**：调色文件改名、丢失内嵌元数据或没有 `.fk.json` 时回导失败，未保存工程重开后也无法回导（UX-07）；“仅画面”导出可能残留约 0.1–0.2 毫米白框（UX-02）；修改片数后旧的数量警告不消失、没有自动识别片数开关（UX-01）；“转正”只改导出方向、没有整张扫描件旋转（UX-04）；同尺寸调色图合成时未应用内容检测出的旋转（FK-002）、无配置文件的调色图未按导出配置文件解释（FK-003）；“移除身份信息”仍可能从扫描件 XMP 复制作者（FK-004）；MinIsWhite 灰度扫描在原始分辨率下显示反相（FK-011）；新建/打开/拖入工程不提示保存（FK-001）；工程损坏时不提供备份恢复（FK-008）。

**已知限制**：未签名/未公证（首次打开见 docs/INSTALL.md）；黑框放在黑色扫描盖上无法识别轮廓（会给出数量警告），请用浅色背板；亮色扫描盖下外框可能比相纸大 0.3–1.4 mm（不会裁进相纸）；屏幕色彩：Windows 上按主显示器的 ICC 配置文件显示（不区分多台显示器），macOS 由系统从 sRGB 转换，尚未用校色仪验证；撤销历史不随项目保存；尚无磁盘缩略图缓存；真实窗口绘制、色彩准确度与 8 GB 设备尚待人工验证（docs/HUMAN-VERIFICATION.md）。
