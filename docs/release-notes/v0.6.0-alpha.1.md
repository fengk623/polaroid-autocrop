## 本版新增

- **可追溯构建**：“帮助 ▸ 关于”显示版本、完整提交 SHA 与构建号（可选中复制）；`--version`、自检报告、macOS Info.plist（FKVersion/FKCommit/FKBuild）、Windows 文件版本资源同样记录；每个安装包附 `BUILDINFO.txt`（版本、提交、构建号、Qt 与各依赖库版本、签名状态）。版本号支持预发布后缀（`0.6.0-alpha.1`）。
- **发布流程**：PR 的测试包取自 PR head 提交；打包后自动检查应用报告的版本与提交是否与包一致；发布时创建唯一 Tag 与 Pre-release，拒绝覆盖已有 Tag/Release，发布后下载核对 SHA-256。
- **问题复现与已知问题测试**：用户反馈的问题在真实扫描上复现并记录（docs/v1/WORKLOG.md）；10 个已确认缺陷各有“修复前失败”的测试（核心 3 个 ctest WILL_FAIL、应用自检 7 个 known-issue），修复后它们会变红并改为常规测试。
- **自检场景**：`FrameKeeper --self-test <目录> --scan <扫描.tif> --scenario relink|count|upright|miniswhite` 按用户操作流程运行并记录实际行为。
- **v1.0 文档集**：开发计划（含审核 12 条）、Unit 清单、26 项追踪表、基线登记、现有功能冻结清单、开发规范检查表、格式能力矩阵、真实扫描真值规范、中文使用指南初稿（docs/v1/）。

## 累计功能

与 v0.5.0 相同：自动识别相片外框/内框、手工编辑、模板、批处理、导出画面区域（TIFF/PNG/JPEG/Linear DNG）、回导与合成到真实扫描相框或生成边框、工程、色彩与隐私选项、中英文界面。详见 docs/v1/FEATURE-FREEZE.md。
