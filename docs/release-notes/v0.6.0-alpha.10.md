## 本版新增 / 修复

- **修复 FK-010**：以前从 16 位扫描件导出 8 位时仍显示“逐像素一致”。现在所有导出提示都来自核心的实际输出计划（尺寸、位深、通道、色彩配置、几何、插值、不一致的原因）。
- **降位深需确认**：16 位 → 8 位必须在导出对话框中勾选确认，否则不能导出（以前默认允许）。
- **画面区域默认“拉正”并标注**：说明旋转角度和 Lanczos-3 重采样；“像素裁切”仍可选，并说明倾斜相片的四角可能带到相框。已经选过模式的用户保持原选择。
- **圆形画面**：PNG/TIFF 圆外透明，JPEG 圆外填白，Linear DNG 保留四角相框；导出前和报告中都会说明。
