## 本版修复与新增

- **过时的后台结果不再覆盖新状态**（FK-006）：
  - 重新识别期间编辑了相片 → 识别结果不再应用，编辑保留，并提示“如需替换请重新识别”。修复前：编辑被识别结果静默覆盖。
  - 合成预览计算期间改了蒙版、边界、转正或回导文件 → 旧预览丢弃。修复前：旧预览被显示和缓存。同一张相片的多次预览请求会合并，新请求取消旧请求。
  - 打开、新建或关闭工程时，正在进行的导出、回导检查等结果不会写进新工程；已写完的导出文件保留，并给出提示。
  - 吸附边缘计算期间如果手动改了外框，以手动修改为准。
- **任务状态如实显示**：任务列表显示 排队中 / 进行中 / 完成 / 失败（附原因）/ 已取消 / 已过期未应用。修复前：失败也显示为“完成”。
- 取消的导出不留下临时文件（`*.fk-tmp-*`）。
