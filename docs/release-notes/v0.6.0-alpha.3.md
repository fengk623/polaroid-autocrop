## 本版新增

- **导出只交付图像文件**：每次导出的几何（内外框、方向、变换）、尺寸、位深、色彩配置、文件名与 SHA-256、内容签名都记录在工程里；调色文件旁边不再需要 `.fk.json`。回导和合成从工程记录取几何。
- **附属文件改为可选**：设置 ▸“导出时同时写入便携附属文件（.fk.json）”，默认关闭。
- **旧工程自动补记录**：打开以前的工程时，仍能读到的 `.fk.json` 会导入工程（下次保存时写入），之后即使附属文件丢失也能回导。

## 兼容性

- 工程格式仍是 `fk.project/1`，只新增顶层字段 `exportRecords`。v0.5.0 及之后的旧版本会原样保留它：新旧版本可以互相打开、编辑、保存，不丢记录。**无需迁移**，可直接回退到旧版本（旧版本只是不会使用这些记录，回导仍需要附属文件）。
- 原计划的“schema v2 + 迁移副本”因此不再需要（理由见 RFC-0009 §Export records）。
