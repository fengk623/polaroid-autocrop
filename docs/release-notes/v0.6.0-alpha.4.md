## 本版新增

- **先选相片再选文件**：右栏“回导”页新增“回导到这张相片…”。改过名、去掉了内嵌信息的调色文件也能回导。
- **证据模型**：文件哈希、内嵌 ID、文件名、画面内容一起判断，不再“第一个命中就算”。回导对话框列出每个文件的候选相片和证据（✓ 支持 / ✗ 矛盾）。
  - 自动选中：文件与导出完全相同；或内嵌 ID/文件名与画面都一致；或你指定的相片与画面一致。
  - 需要你选择：只有画面相似、多个相片或导出版本都符合、或证据互相矛盾。文件名或相似的画面不会压过更强的矛盾证据。
  - 没有匹配时，在下拉框中“指定为 P0x …”，软件针对这张相片重新检查。
- **编辑软件后缀**：`_1` 这类后缀现在也会去掉后再按文件名匹配（此前已支持 `-Edit`、`_edit`、` copy`、` (1)`、`-1`）。
- **新建对位**：相片在本工程中没有导出记录时（由另一个工程导出，或导出后没保存就退出），可以把调色图明确地放到这张相片当前的画面区域上。按调色图尺寸选择“不旋转裁切”或“拉正”形状；宽高比相差超过 0.5% 时拒绝，不拉伸；不会自动勾选；工程中记为“手动对位”，不伪造导出历史。
- **拖入分流**：拖进窗口的 TIFF 带有 FrameKeeper 内嵌信息或导出文件名时当作调色文件回导，其他 TIFF 当作扫描件导入。
- 回导入口在工程中有相片时即可使用（以前要求先导出）。

## 已知问题与未验证内容

- 与导出尺寸相同、方向被旋转的调色图，合成时不会自动转回（FK-002，U005）。
- 导出后未保存工程就退出时，边框修改无法恢复（U008 增加恢复快照）；回导可用“新建对位”。
- 画面很平淡（雾、雪、大面积纯色）时画面比对可能低于阈值，需要手动确认。
- 图 14（Windows 回导对话框文件名空白）仍需在 Windows 真机复现（FK-009）。
- 其他已知问题仍存在：UX-01、FK-004、FK-007、FK-008、FK-010、FK-011。
- 离屏验证，真实窗口待验收；安装包未签名。
