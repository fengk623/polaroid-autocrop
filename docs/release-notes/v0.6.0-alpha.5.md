## 本版新增 / 修复

- **修复 FK-002**：调色时旋转了 180°（尺寸不变）的文件，以前合成时不会转回。现在回导时按尺寸限定可能的方向，再用画面判断；确认的方向随关联保存，预览和最终输出都按保存值使用，保存后重新打开也一样。
- **方向不确定时由你选择**：画面对称或纹理少、分辨不出方向时，回导对话框“方向”一栏要求手动选择，未选择不能勾选。
- **勾选即确认**：有旋转或缩放的文件不再自动勾选；勾选同时确认方向、缩放到导出尺寸和较低位深。最终输出不再重复询问这些（旧版本做的关联除外）。
- **关联后文件被改动**：尺寸与确认时不同会拒绝输出并提示重新关联（完整的变更校验在 U007）。
- 修复 U004 回导对话框：唯一匹配时下拉框仍显示“选择相片…”。
- 测试：已知问题检查的前提不满足时（例如 8 位扫描上的 16 位问题）记为“不适用”，不再误报。
