## 本版新增 / 修复

- **修复 FK-003**：调色软件去掉了 ICC 配置时，以前会默认当作扫描件的色彩空间——导出时若转换过色彩空间（例如 Adobe RGB 扫描导出为 sRGB），合成后颜色会偏。现在回导时必须确认如何解读颜色：
  - 能按文件哈希识别导出时的配置时预先选好它；也可选扫描件配置、sRGB、Adobe RGB 或 .icc/.icm 配置文件。
  - 内嵌配置无法读取时不预选，必须手动选择；无法读取的配置文件会被拒绝。
  - 勾选即确认；未选择不会关联。
- **保存**：选择与配置文件内容保存在工程里，重新打开工程、原配置文件不在时也能照样输出；合成只转换一次，相框像素不变。
- 旧版本做的关联：能识别导出配置时按它解读（旧版对话框承诺的“按导出配置”），否则提示重新关联。
