## 本版新增 / 修复

- **修复 FK-007**：同一路径被换成另一个同名同大小的文件时，以前会被当作原扫描使用。现在导入时计算整个扫描文件的哈希，打开、识别和每次输出前都在后台核对（大小 → 首尾 → 全文件）；不一致时扫描件显示“已改动”及原因，不会再用它输出，可用“重新定位…”按内容找回原文件。
- **读取中改动**：输出任务在读取前后比较文件大小和修改时间，中途被改动则丢弃这次输出。
- **调色文件被覆盖**：哈希不同时重新检查——尺寸、确认方向下的画面、内嵌色彩配置都不变，视为再次调色，照常使用并提示；否则拒绝并说明原因（尺寸 / 画面 / 色彩配置），需要重新关联。
- 旧工程的扫描件在下次打开时补算整文件哈希。
