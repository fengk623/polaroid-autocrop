## 本版新增 / 修复

- **修复 FK-001**：以前只有退出时会提示保存；新建、打开、拖入工程会直接替换当前工程。现在新建、打开（菜单、快捷键、最近、拖入）、恢复备份、恢复未保存工作和退出都会询问“保存 / 不保存 / 取消”，并说明会取消的后台任务。保存失败或取消选择保存位置时，工程、路径和未保存状态保持不变（以前另存为失败后路径会被改掉）。
- **修复 FK-008**：工程文件损坏时，若备份完好会询问是否恢复；恢复时损坏文件改名保留，备份内容以未保存状态打开。损坏的文件不会再覆盖好的备份。
- **恢复快照**：有未保存修改时，几秒后在应用数据目录写一份快照（不写你的工程文件）；异常退出后下次启动可恢复，也可从“文件 ▸ 恢复未保存的工作…”打开。
- **输出参数随工程保存**：几何、转正、最终输出、蒙版、边框等参数保存在工程里。
