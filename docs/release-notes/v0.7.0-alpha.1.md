## 本版新增 / 修复

- **自动识别相片数（默认开启）**：左栏“识别”新增开关。开启时数字置灰并显示实际识别到的相片数，不再因默认 4 张或以前填写的数量提示“数量不符”。单张、四张扫描件可以在同一批里混合。
- **每个扫描件单独设置**：关闭自动后填写期望数量（1–12）；数量不符时提示“识别到 N 张相片，预期 M 张”。**改开关或数量后提示立即更新**，不需要重新识别（修复以前提示不消失的问题）。再次关闭自动时恢复上次填写的数量。设置随工程保存；新扫描件的默认值在“设置”中修改。
- **自动模式下保留的提示**：低置信度相片；新增“另有 N 个物体可能是未识别出的相片”（疑似漏检）；“未找到相片”（空白扫描件，或边框与背景太接近）；超过 12 个物体时只保留最大的 12 个。数量只用于核对，不会为凑数量画框或合并目标。
- **附带修复**：新建工程后画布仍显示上一个工程的扫描件；设置从配置文件读回时布尔值/数字变成文字，导致个别勾选框在重启后显示不对。

## 已知问题与未验证内容

- 疑似漏检依据颜色差（约 ΔE 1.5 以上、形状像相片）：和背景完全一样的相片仍可能没有提示；提示的物体也可能不是相片（例如背板上的标签），需要人工看一眼。
- 识别精度（白底白框、内框偏移）在 U012 改进。其他已知问题：FK-011。
- 自检报告新增“跳过”（前提不满足，例如没有色彩配置的扫描件不能做色彩转换检查），并在打包检查中列出。
- 离屏验证，真实窗口待验收；安装包未签名。

## 工程格式

同一 schema `fk.project/1` 内新增可选字段：扫描件 `detection.autoCount`、工程 `settings.autoCount`。旧工程的扫描件保持原来的手动数量；新扫描件默认自动。更早的版本会忽略并在保存时丢掉这两个字段（使用保存的手动数量）。
