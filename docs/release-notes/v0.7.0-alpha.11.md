## 本版新增 / 修复

- **边缘折叠条**：左栏、右栏、胶片条各有一条 8 px 的折叠条，贴在窗口左边缘、右边缘、底边缘。单击折叠/展开；面板折叠后折叠条不移动，可以原地再点开；箭头指向点击后面板移动的方向；悬停提示“隐藏/显示左侧栏（Ctrl+Alt+1）”等；可用 Tab 聚焦后按空格或回车。
- **命中区域**：在相邻的空白内边距上再延伸 6 px（共 14 px），不覆盖滚动条：右栏展开时右折叠条、胶片条折叠时底折叠条只用 8 px。
- **全宽胶片条**：胶片条横跨整个窗口宽度，左右栏在它上方结束；上方仍是左栏、中央画布、右栏，最顶部是菜单（macOS 为系统菜单栏）。
- **顶栏**：去掉 ◧/◨ 两个按钮。视图菜单“左侧栏 / 右侧栏 / 胶片条 / 所有面板”和 Ctrl+Alt+1/2/3/0（macOS ⌥⌘1/2/3/0）保留。
- **重置布局**：恢复默认栏宽，同时显示所有面板（以前只恢复栏宽）。
- 栏宽（拖动栏边缘手柄）和折叠状态写入设置，下次启动保留。画布处于“适合”时，折叠、展开、改变窗口大小后重新适合，完整显示扫描件。

## 已知问题与未验证内容

- 真实窗口：Windows 150 %/200 %、macOS Retina 下折叠条的外观与命中需真机确认（与 FK-009 / U024 一起记录）。
- **顶栏在最小窗口宽度溢出（原有问题，本版测试发现）**：1100×700 且两栏默认宽度时，中列只有 528 px，顶栏需要约 770 px，对比/叠加线/缩放按钮被右栏遮住（快捷键与视图菜单可用）。自检记为 known-issue（UX-06），在 U021 调整顶栏时修复。
- 系统窗口边框：窗口未最大化时，Windows 的窗口缩放边框在客户区外侧，与折叠条相邻；真机上需确认不会误触缩放。
