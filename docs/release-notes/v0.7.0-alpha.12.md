## 本版新增 / 修复

- **视图切换位置**：扫描件 / 相片 / 画面 / 合成 移到右侧眼睛按钮（叠加线）与缩放数值之间。数字键 1–4、“视图”菜单不变。
- **窄窗口不溢出**（修复 U022 发现的问题：1100×700、两栏默认宽度时顶栏约 770 px、中列 528 px，叠加线与缩放按钮被右栏遮住）：中列不够时顶栏依次省去 导入/导出/重新关联 按钮（文件菜单、左栏仍有）→ 视图切换改为同样四项的下拉按钮 → 缩放 − / +（缩放数值菜单、快捷键仍有）。顺序始终是眼睛 → 视图 → 缩放，不出顶栏、不互相重叠。
- **画布最小宽度**：窗口过窄时左右栏按各自可让出的宽度成比例变窄（不低于最小宽度），画布至少 480 px；保存的栏宽不变，加宽窗口后恢复。
- **步骤提示**：右栏标题下方显示当前相片的五个步骤：导入 · 识别 / 复核 · 导出画面区域 · 重新关联 · 合成 / 最终输出。已完成为实心带勾，下一步带圆环，下方写“下一步：…（第 n 步，共 5 步）”。点击转到该步：导入对话框、右栏“边界 / 导出 / 导回”页，第 5 步同时切到“合成”视图。
