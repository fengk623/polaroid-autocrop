## 本版新增 / 修复

- **文字与排版自动检查**（以前自检只确认截图非空）：窗口中每一段可见文字都检查——有没有字形（不显示方框）、是否超出自己的框或窗口、是否被所在面板在侧面裁掉；标签、分组标题、分段按钮和按钮文字不得被省略（路径、文件名等值可以省略）；折叠条、顶栏按钮、视图切换、缩放和步骤提示不得被其他内容盖住。覆盖深色/浅色、1100×700 / 1440×900 / 1920×1080、侧栏显示/折叠、右栏三页，以及设置、关于、导出对话框。CI 在 Windows、macOS、Linux 上以英文 1×、1.5× 和中文 1×、2× 运行。
- **修复：右栏“导回”页比右栏宽**：“回导到这张相片…”和“重新关联调色后文件…”两个按钮排在一行（约 358 px），把整页撑得比右栏（300 px）还宽，右侧的说明文字、下拉框和按钮被裁掉（中文界面尤其明显）。按钮现在自动换行；“最终输出 ▸ 相框”的两个选项放到标签下一行。
- **修复：设置对话框“新相片的蒙版”标签被省略**：字段标签过长时换到第二行，不再省略，也不会把侧栏撑宽。
- **查明并修复：Windows 离屏自检截图里的文字方框（FK-009 历史问题）**：Qt 离屏平台在 Windows 上只从 `QT_QPA_FONTDIR` 或 Qt 自带的字体目录读字体，安装的 Qt 没有字体目录，于是退回“方框字体引擎”——每个字都画成方框、宽度约等于字号，文字量出来比实际宽很多，侧栏被撑宽，步骤提示跑出窗口（PR #25 的 Windows 失败）。自检在 Windows 离屏启动时改用系统字体目录（只影响自检，不影响软件本身）；字形检查也能识别这种方框字体。
- **修复：所有者扫描件 polaroid_92 上右栏比栏宽 7 px**：相片的胶片类型（“Polaroid 600 / i-Type / SX-70”，165 px）和置信度（“Check recommended  80 %”，159 px）这类数值文字按自身宽度排版，较长时把整栏撑到 307 px，右侧约 7 px 被裁掉、盖在折叠条上（1100×700 窗口）。数值文字现在填满剩余宽度并在需要时换行。超宽报告现在会指出撑宽侧栏的那一行及其中的文字。
- **Windows 离屏自检的中文字体**：Qt 离屏平台在 Windows 上的字体库只读取 .ttf/.otf，不读 Windows 中文字体所在的 .ttc 字体集，也没有字体回退，因此中文画成方框。自检现在加载 `msyh.ttc`、`msyhbd.ttc`、`simsun.ttc`，并按 Windows 的顺序设置回退字体（含 Segoe UI Symbol，用于中文句子里的“⚠”）。只影响自检，不影响软件本身（真实窗口使用系统字体回退）。
- **修复：8 位导出被拒绝时的提示末尾出现给程序员看的说明**“(set allowDepthReduction after the user confirms)”：需要确认的提示不再附带技术细节（细节写入日志）。
