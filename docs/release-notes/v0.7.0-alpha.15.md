## 本版新增 / 修复

- **许可证文本进入安装包**：`licenses/` 文件夹包含六个依赖库的原始许可证文本、Qt 的 LGPL-3.0（及其所依据的 GPL-3.0）、Qt 源码链接与替换 Qt 库的说明，以及由 Qt 自身归属文件生成的 Qt 内部第三方组件（FreeType、HarfBuzz、PCRE2 等 46 项）声明。此前 `THIRD-PARTY-LICENSES.md` 声称安装包里有这些文本，实际只有 `LICENSE` 和该文件。
- **按用户实际拿到的方式检查安装包**（发布工作流，干净运行器）：
  - macOS：挂载 DMG → 检查内容、许可证、BUILDINFO、Info.plist 版本与签名 → 复制到“应用程序”并运行自检（arm64 与 x86_64）→ 用最新已发布版本做 升级 / 回退 / 再升级（替换应用），每一步核对用户数据。
  - Windows 免安装版：解压 ZIP → 检查 → 在没有 Qt 的 PATH 下运行自检。
  - Windows 安装版：全新安装 → 文件与包一致、文件关联、开始菜单 → 运行自检 → 卸载（程序、注册、关联、快捷方式移除）；从每个已发布版本升级、回退到最新已发布版本、再升级、卸载；设置、模板、恢复文件和工程在每一步及卸载后逐字节不变；Qt 插件与 QML 文件夹无残留。
  - SHA-256 生成后立即校验。叠放的 Unit PR（指向 `unit/**`）现在也会生成并检查测试包。
- **工程兼容与回退**：打开再保存时，更新版本写入的未知内容在每一层都原样保留（此前只保留顶层），因此回退到本版本再升级不会丢失任何内容；工程最后由更新版本保存时，打开会提示。0.5.0 与 0.6.0-alpha.1 用其自身代码写出的工程、导出记录、模板作为测试样本，全部字段可正确读取；本版本工程经 0.6.0-alpha.1 打开保存后保留与丢失的内容已实测并写入文档。
- **文档更正**：使用指南曾写“新版本改变格式时提示迁移为新副本”——从未实现，已更正；发布检查表仍写“生成草稿再由所有者发布”，已按实际工作流更正。（本 Unit 工作中还发现 PRD 中 14 个不存在的测试与 `tools/check-claims.py` 的漏洞，已在 U027 中改正。）

## 已知问题与未验证内容

- 代码签名与公证未做：需要证书与费用，由所有者决定。Windows 未签名（SmartScreen 提示），macOS 临时签名、未公证（首次打开需确认）。
- 真机安装、升级、卸载（HV-08、HV-09）未验收；CI 运行器上无界面的验证不包含 SmartScreen、开始菜单点击、双击 `.fkproj` 等真实桌面行为。
- 回退到 0.6.0-alpha.1 或 0.5.0 后在旧版本中保存，会丢失上表列出的较新字段（这些旧版本只保留顶层未知字段）；从本版本起不再有此问题。
- 旧版本安装程序回退时不会清理新版本多出的顶层文件（只列出，不影响运行）；本版本起安装程序会整体替换插件与 QML 文件夹。
- 图库尚未实现（U018–U020 待所有者确认 RFC），其存储位置届时加入同一套安装/升级/卸载检查。
