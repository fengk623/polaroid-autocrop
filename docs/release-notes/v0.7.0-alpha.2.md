## 本版新增 / 修复

- **白底白框的外框不再包含阴影带**：外框从纸面一侧找纸边，排除纸边外的阴影带和扫描盖亮带。所有者 826 dpi 白底扫描件上，外框比纸边宽出的距离从 0.9–1.9 mm 降到 0.1–0.5 mm，且没有切到纸面。
- **紧裁扫描件不再切纸**：单张扫描中纸面伸出扫描范围的一边，外框改为贴扫描边界（以前会把这一边斜着切进纸面 3–5 像素）。
- **“仅画面”拉正导出不再带相框**：画面四边精确对到输出四边（仍只重采样一次）。以前按外框角度旋转再取外接矩形，扫描仪轻微歪斜（约 0.3°）或紧裁扫描时每边留下 6–17 像素白边。以前导出的文件仍按当时的几何回导。
- **真实扫描评估工具**：`fkcli realeval` 按真值文件逐边计算外框切入/外扩、内框误差、拉正导出覆盖，按 DPI/位深/背景/形状分层；`tools/gt/draft-gt.py` 只根据像素起草真值（需所有者复核）。

## 已知问题与未验证内容

- **真值是草稿**（`agent-draft`），需所有者复核后才能作为验收依据；白底白框没有回归样本（img20260702 无法传入），圆形画面、深色背景、1600 DPI 没有真实样本——门槛只在调参集上满足，泛化尚未证明。
- 纸边本身明显发暗（脏污）且放在浅色背板上时，外框可能偏里（RFC-0004 §Known limits）。
- 生成扫描件中发现一例：误判扫描比例（`dpi_rescaled`），Instax Mini 内框一边偏 47 像素（低置信度提示，与旧版相同，未修复）。
- 其他已知问题：FK-011。离屏验证，真实窗口待验收；安装包未签名。
