## 本版新增 / 修复

- **轻按 Shift 切换外框 ↔ 内框**（默认开启，可在设置中关闭）：单独按下并松开 Shift 才切换；画布顶部中间始终写明“正在编辑外框（纸边）/ 内框（画面区域）”，并配外框/内框的颜色标记（不只靠颜色）。
- **按住 Shift 只做约束、不切换**：矩形角点保持直角、宽高比和倾斜角，以对角为固定点等比缩放（不会变梯形）；整体/圆心沿水平或竖直方向移动；椭圆两个半径等比；圆形始终 rx = ry。拖动中按下或松开 Shift 立即生效。自由角点编辑仍是默认。
- **不会误切换**：Shift+单击、Shift+字母、Shift+方向键、Shift+滚轮、按住超过 1 秒、在输入框中打字、对话框或菜单打开、窗口失去焦点、拖动进行中，都不切换。
- **菜单和工具按钮同样可用**：“相片 ▸ 编辑外框 / 编辑内框 / 切换外框 ↔ 内框”，工具栏按钮与 O / I 键。
- **一次完整拖动 = 一步撤销**；拖动中失去焦点或按 Esc：拖动作废，边界不变；没有变化的操作不产生撤销步骤。
- 修复：选中控制点时 Shift+← / → 会切换扫描件而不是按 10 像素微调；用方向键微调圆形的半径会把圆变成椭圆；旋转后的椭圆半径控制点不在轮廓上；平移加旋转会让圆的两个半径在末位产生差异。

## 已知问题与未验证内容

- 自检在离屏平台上注入输入事件；真实窗口（尤其 macOS 原生菜单、输入法激活时的 Shift）待所有者验收。macOS 原生菜单无法在离屏中点击，该项在 macOS 测试包中记为“跳过”。
- “窗口失去焦点”在自检中以发给窗口的 FocusOut 事件模拟，不等同于真实切换应用。
- 边中点拖动不受 Shift 约束（边本来只沿法线移动，矩形保持矩形）。
- 其他已知问题：FK-011。安装包未签名。
