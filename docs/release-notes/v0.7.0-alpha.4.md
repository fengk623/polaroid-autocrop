## 本版新增 / 修复

- **整张扫描件旋转**：“相片 ▸ 整张扫描件逆时针旋转 90° / 顺时针旋转 90°”，左栏“识别”中的“整张扫描件”按钮（显示当前角度），扫描件列表右键菜单。所有相片、外框/内框、扫描件缩略图、导航图、点选与编辑都一起转，识别结果数量不变。
- **非破坏**：旋转只记在工程里（`view.rotation`），扫描文件不改写、边界一律保存在扫描文件坐标中；连续 4 次回到原样；一次撤销恢复整张（与相片编辑按顺序交错撤销/重做）；保存重开保持。
- **导出方向不叠加**：应用转正（默认）时按每张相片自己的方向导出，整张旋转不叠加；不应用转正时按画布方向导出（无损 90° 转向）。旋转前导出的文件在旋转后照常重新关联，最终合成与整张相片逐位一致。
- **改名避免混淆**：原“向左/右旋转至正向”改为“本张相片转正：向左 / 向右”（右栏“本张转正”），只改变一张相片的导出方向。
