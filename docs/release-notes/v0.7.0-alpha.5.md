## 本版新增 / 修复

- **新相片默认自然融合**：羽化 0.05 mm（按扫描件分辨率换算：800 / 1200 / 1600 dpi 约 1.6 / 2.4 / 3.1 像素；没有可靠分辨率时 2.4 像素），过渡全部在画面区域内，相框像素始终不变。保留边缘预设 0.02 mm（约 0.63 / 0.94 / 1.26 像素）；硬边缘 0 像素作为档案精确选项保留。
- **每张相片单独保存蒙版**：右栏“回导 ▸ 蒙版”修改的是当前相片（可直接输入宽度、可撤销）；“应用到所选的 N 张相片”才会批量修改；“设置 ▸ 新相片的蒙版”决定新相片用哪一种。以前工程里的相片保持原来的设置，不被改动。
- **预览与最终导出用同一蒙版**（同一个换算函数）；没有修改的调色文件在任何蒙版下合成都与原扫描逐位一致。
- **边缘变化大时提示**：合成预览测量画面边缘内侧的颜色变化，超过阈值时提示在 100% 下检查、必要时加宽蒙版或检查对齐（强烈改色、错位不承诺单一默认值无痕）。
- **默认值如何选的**：新工具 `fkcli maskeval` 在你的 4 个扫描件 7 张相片（真值草稿）上，把画面区域按像素裁切导出、做常见调色（曝光、暖色、对比、褪色）后按最终导出的方式合成回去，测量 50% 显示时的接缝、相框被调色的程度和未调色的残边。所有相片在正常调色下的最坏接缝：硬边缘 6.61 → 羽化 0.05 mm 3.64（ΔE00，每一张都更好），残边 ≤ 0.33 像素；建议的试验值 0.03 mm 为 4.71。详表见 RFC-0007 §Natural blend。

## 已知问题与未验证内容

- **剩余接缝来自识别误差**：识别出的画面区域略大于真实窗口时，靠边的真实相框像素会被部分调色；蒙版只能淡化，不能把边缘往外移（UX-02 识别精度）。
- 真实样本只有 826 / 1200 dpi、矩形画面；没有 1600 dpi 和圆形画面；真值仍是草稿。ΔE00 按 sRGB 数值计算。
- 右栏部分行在默认 300 px 宽度下被截断（已有问题，见 FK-009 / U024）。
- 其他已知问题：FK-011。安装包未签名。
