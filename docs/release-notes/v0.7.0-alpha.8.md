## 修改前的问题（已复现 / 源码确认）

- MinIsWhite 灰度扫描件：读取时已经反相，显示时又反相一次 → 预览正常、100% 原始分辨率是负片（同一行亮度：预览 15.8，原始分辨率 239.2）。
- Windows 启动时只读取主显示器的 ICC，之后不再更新：窗口拖到另一台显示器、插拔显示器或更换配置文件后，仍按旧配置文件显示。

## 本版新增 / 修复

- MinIsWhite 8/16-bit：预览与原始分辨率亮度一致（修复后两者均为 15.8）。
- Windows：按窗口所在显示器的 ICC 显示；换屏、显示器增减、每 5 秒检查配置文件变化。配置文件变化时：屏幕上的预览图立即转换，并从扫描件重新读取（精确）；100% 原始分辨率补丁与合成预览重新生成；缩略图从旧配置文件转换到新配置文件；其他扫描件的预览图显示时重新读取。为旧配置文件生成、仍在进行的结果不会显示。
- “关于”对话框显示正在使用的显示配置文件及来源。
- 显示转换不改变扫描件，也不改变导出文件（自检：换配置文件前后导出逐像素一致）。
