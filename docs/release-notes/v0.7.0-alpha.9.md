## 本版新增 / 修复

- 图标去掉太阳；相纸、白边、识别角标和配色保持不变（不改名、不换品牌）。
- 每个尺寸单独绘制：16/24/32 px 下角标描边至少约 1 像素，不再从 1024 px 缩小而发虚。
- macOS 图标文件补齐 1× 16/32/64 px 条目（列表视图、1× 显示器使用）。
- 应用内图标、Windows 程序/安装器/文件关联、macOS 程序包使用同一批生成文件。
