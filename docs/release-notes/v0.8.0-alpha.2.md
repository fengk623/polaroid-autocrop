## 本版新增 / 修复

- **两个工作区**：左上角（左栏顶部，原来写“工程”的位置）是“图库 / 修改照片”切换，按 G / D 也能切换。第一次启动进入图库工作区，之后记住上次的工作区。图库工作区里，修改照片用的单键快捷键不起作用。
- **图库首页**：每个打开过的图库一张卡片——封面（保存图库时取封面相纸的缩略图）、名称、扫描件数和相纸数、最近打开时间、修改时间，以及“已打开 / 只读 / 正在别处使用 / 找不到”标记。卡片只读 `library.json`，不读目录文件，图库再大首页也快。
- **操作**：新建图库、打开图库、导入工程；双击卡片进入图库（暂时进入“修改照片”，图库内网格在 U020 加入）；卡片菜单：打开、重命名（只改名称，文件夹名不变；另一个 FrameKeeper 正在使用时不能改）、在访达 / 资源管理器中显示、从列表中移除（文件夹不删）。
