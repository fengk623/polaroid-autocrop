## 本版新增 / 修复

- **进入图库**：双击首页卡片进入图库，显示它的相纸；左栏“全部图库”回到首页。
- **网格 / 单张**：G 网格，E 单张（← / → 切换）。网格只为屏幕上看得见的格子读取缩略图；缩略图存在图库的 `cache/thumbs` 里，按扫描件内容和相纸外框命名，边界改动后不会显示旧图。打开图库时只解码选中的扫描件。
- **相纸 / 扫描件**：两种列表，显示各自数量；双击扫描件只看它的相纸。左栏列出图库的文件夹（引用，不复制），底部是导入 / 导出。
- **排序**：拍摄时间、添加顺序、编辑时间、编辑次数、星级、选取、文本标签、颜色标签、文件名、像素尺寸、扩展名、文件类型、长宽比、手动排序，升序或降序。没有值的项目两个方向都排最后；值相同的保持原来的顺序。每种列表各记一份排序，存在图库里。
- **筛选**：星级、选取状态、颜色标签、文字（文件名或文本标签）。
- **评级与标签**：键盘 0–5 星级、6–9 颜色（红黄绿蓝）、P 选取、X 排除、U 取消；右栏可点星星、选取、颜色，填写文本标签；手动排序在格子的“⋯”菜单里。全部保存在图库目录中。
- **信息**：文件名、所在图库、版权、拍摄者、拍摄时间、扫描时间、像素尺寸、文件大小、DPI；没有记录的显示“未知”。拍摄时间只取自照片的 EXIF 拍摄时间，扫描时间单独显示。隐私预设为“移除身份信息”时，拍摄者下方注明导出时不写入。
- **编辑与返回**：双击相纸（或 Enter）转到“修改照片”；按 G 回到网格，仍选中同一张。修改照片中的编辑会记录编辑时间和次数。
