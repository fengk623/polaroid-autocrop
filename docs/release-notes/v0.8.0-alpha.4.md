## 本版新增 / 修复

- **分工**：图库工作区管理图库和工程（新建 / 打开 / 导入图库，打开工程…，新建工程）；修改照片工作区做编辑，左栏只保留当前名称、保存、导入扫描件和回到图库的“图库…”按钮。在图库工作区打开或新建工程会直接转到修改照片。所有命令仍在“文件”菜单里。
- **切换只是换视图**：缩放、画面位置、选中的相纸、未保存的修改和正在运行的后台任务都保持不变。
