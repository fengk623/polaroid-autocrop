# 现有功能冻结清单（v0.5.0 基线）

v1.0 改动前的全部现有功能。需求文档：“所有未提及功能必须保留，不得借重构删除、降级或改变其既有行为”。
每个 Unit 发布前核对受影响条目；U021/U029 做全量回归。条目被需求明确修改时，在“v1.0 变化”一栏写明需求编号；
其他任何变化须先写影响说明并取得确认。来源：`app/qml/*.qml`、`app/src/AppController.*`、`tools/cli`（2026-10-30）。
