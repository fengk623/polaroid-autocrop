# FrameKeeper 使用指南（中文）

适用版本：**0.6.0-alpha.7**（随每个开发版本更新；每节标注“本版行为”与“已知限制”）。
最后更新：2026-10-30。版本号与构建信息见“帮助 ▸ 关于 FrameKeeper”。

> 本指南描述当前版本**实际能做的事**。尚未实现的 v1.0 功能（图库、整张扫描件旋转等）在
> “已知限制”中列出，实现后再写入正文。

## 1. 安装与升级

- **macOS 12 及以上**：打开 `FrameKeeper-<版本>-macOS-universal.dmg`，把 FrameKeeper 拖到“应用程序”。尚未公证，首次打开请在“应用程序”中右键 ▸ 打开 ▸ 打开（macOS 15：先打开一次，再到“系统设置 ▸ 隐私与安全性 ▸ 仍要打开”）。
- **Windows 10/11 64 位**：运行 `…-Windows-x64-Setup.exe`（默认只为当前用户安装，无需管理员），或解压 `…-portable.zip` 后运行 `FrameKeeper.exe`。尚未签名，SmartScreen 提示时点“更多信息 ▸ 仍要运行”。
- **校验**：下载页的 `SHA256SUMS.txt` 与每个包内的 `BUILDINFO.txt`（版本、完整提交、构建号）可用于核对。
- **升级**：安装新版覆盖即可；工程文件（`.fkproj`）不会被安装程序改动。新版本若改变工程格式，会在打开旧工程时提示“迁移为新副本”，原文件保持不变（自 U003 起）。

## 2. 基本流程

1. **导入扫描件**：把 TIFF 扫描拖进窗口，或“文件 ▸ 导入扫描件…”（Ctrl+I）/“导入文件夹…”（Ctrl+Shift+I）。扫描件只读，永不修改。
2. **识别与复核**：导入后自动识别每张相片。蓝线 = 外框（整张相纸，含白框），黄线 = 内框（画面）。红色点划线表示“需要复核”。
3. **导出画面区域**：右栏“导出”或 Ctrl+E，把每张相片的画面导出给调色软件。
4. **外部调色**：在 Photoshop / Lightroom / Capture One 中调色并保存。
5. **回导**：“重新关联调色后文件…”（Ctrl+Alt+I）选择调色后的文件；或在右栏“回导”页点“回导到这张相片…”，先选相片、再选文件。
6. **合成与最终输出**：合成视图（4）查看效果，“最终导出…”（Ctrl+Shift+E）。

## 3. 识别

- **每个扫描件相片数**：左栏“识别”中设置期望数量（1–12，默认 4）。数量不符会提示。
  - 本版已知限制：修改数量后旧的“数量不符”提示不会消失，需“重新识别”；没有“自动识别片数”开关（U011 实现）。
- **方式**：自动 / 模板（相同扫描托架可保存模板复用）。
- **安全边距**：右栏“安全边距”，下次识别生效。
- 建议：黑框相片请用浅色背板扫描；白底上的白框可能识别偏松（外框落在纸边亮带上，约 0.8–0.9 mm，U012 改进）。

## 4. 编辑边界

- 工具：选择 V、抓手 H（按住空格临时抓手）、编辑外框 O、编辑内框 I、Esc 回到选择。
- 拖动角点或边中点调整；方向键微调（Shift 每次 10 像素）；右栏可直接输入四角坐标。
- 内框形状：矩形 / 圆形。外框可“吸附边缘”；“重置为识别结果”恢复自动结果。
- 撤销 Ctrl+Z / 重做 Ctrl+Shift+Z（每张相片最多 100 步，关闭软件后不保留）。
- 本版已知限制：没有 Shift 快速切换内外框、没有锁定形状的拖动（U013）。

## 5. 旋转

- “相片 ▸ 向左/右旋转至正向”（Ctrl+[ / Ctrl+]）只改变**导出方向**，画布上不旋转。
- 本版已知限制：没有整张扫描件旋转（U014 实现）。

## 6. 导出画面区域

- 格式：TIFF / PNG / JPEG / Linear DNG；位深：与扫描件相同 / 8 / 16；TIFF 压缩：LZW / ZIP / 无。
- 几何：**像素裁切**（不重采样；倾斜相片的轴对齐裁切可能带角部白框）或 **拉直**（Lanczos-3 重采样一次）。
- 色彩：保留扫描件配置文件 / 转 sRGB / 转 Adobe RGB / 不嵌入。隐私：保留安全字段 / 移除位置 / 移除位置与身份（GPS 从不复制）。
- 永不覆盖已有文件，版本号自动递增（`_EDIT_v001`、`_EDIT_v002`…）。
- 只写出图像文件。每次导出的几何、色彩和文件信息记录在**工程**里（不再需要旁边的 `.fk.json`）；导出后请保存工程。需要让其他工程识别调色文件时，可在“设置”中开启“导出时同时写入便携附属文件（.fk.json）”。
- 本版已知限制：内框可能比画面窗口偏外 0.1–0.2 mm，导出边缘留细白边（U010/U012）；16-bit 改 8-bit 导出时仍显示“逐像素一致”（U010）；“移除身份”可能仍从扫描件 XMP 带出作者（U009）。

## 7. 回导与合成

- **两种回导方式**：
  - **按文件找相片**：“重新关联调色后文件…”（Ctrl+Alt+I），或把调色文件拖进窗口。带有 FrameKeeper 内嵌信息或导出文件名的 TIFF 会当作调色文件；其他 TIFF 当作新扫描件导入。
  - **先选相片**（推荐给改过名、去掉了元数据的文件）：选中相片 → 右栏“回导”页 →“回导到这张相片…”。
- **匹配依据（证据）**：文件哈希（与导出文件完全相同）、内嵌 ID、文件名（自动去掉编辑软件加的 `-Edit`、`_edit`、` copy`、` (1)`、`-1`、`_1` 等后缀）、画面内容（四个方向比较）。对话框里每个文件都会列出这些证据（✓ 支持、✗ 矛盾）。
  - **自动选中**：文件哈希一致；或内嵌 ID/文件名与画面都一致；或你指定的相片与画面一致。
  - **需要你选择**：只有画面相似、多张相片或多个导出版本都符合、或证据互相矛盾（例如内嵌 ID 指向 P01，画面却像 P02）。软件不会替你决定，在下拉框中选择相片或导出版本。
  - **没有匹配**：在下拉框里选“指定为 P0x …”，软件会针对这张相片重新检查。
  - 文件名或相似的画面**不会**压过与之矛盾的更强证据。
- **新建对位**：相片在本工程里没有导出记录（由另一个工程导出，或导出后没保存工程就退出）时，指定这张相片后可以“新建对位”：把调色图放到这张相片**当前**的画面区域上。
  - 形状：调色图尺寸与“不旋转裁切”或“拉正后的画面区域”完全相同时用那个形状；否则按宽高比更接近的一种；两种都接近时按画面内容判断。
  - 宽高比相差超过 0.5% 时拒绝（提示先裁切或缩放到画面区域），**不会拉伸**。
  - 新建对位**不会自动勾选**，需要你确认。工程里记为“手动对位”，不是导出记录，不会伪造导出时间。
  - 检查之后、点“重新关联”之前若修改了这张相片的边框，这次对位不会应用，需要重新检查。
- **方向与尺寸（勾选即确认）**：调色时把图转过 90°/180°/270° 或改了尺寸都可以回导。
  - 软件先按尺寸判断可能的方向（长宽不变：0° 或 180°；长宽互换：90° 或 270°；正方形画面：四个方向都可能），再用画面比对决定。
  - 画面能明确分辨方向时自动选好（对话框“方向”一栏显示，例如“旋转了 180° · 画面 97 %”）；画面对称或纹理很少、分辨不出时，“方向”一栏显示“选择方向…”，必须手动选择后才能勾选。
  - 有旋转或缩放的文件不会自动勾选；**勾选即确认**方向、缩放和较低位深，这些随关联保存在工程里，预览和最终输出都按它使用，保存后重新打开也一样。
  - 关联之后调色文件尺寸又变了，输出会提示“调色后文件在关联之后被修改”，需要重新关联。
  - 宽高比不同（另行裁切过）的文件不会被拉伸，需要先裁切或缩放到画面区域。
- **没有色彩配置的调色文件**：有些软件保存时会去掉 ICC 配置，或写入无法读取的配置。这时回导对话框会出现“没有色彩配置；颜色按以下配置解读”：
  - 能确认导出时用的配置（例如导出时转换成了 sRGB 或 Adobe RGB）时，会预先选好“导出时的配置”；也可以改选扫描件的配置、sRGB、Adobe RGB，或点“配置文件…”选择 .icc/.icm 文件。
  - 内嵌配置无法读取时不会预先选择，必须手动选择。
  - 选择后需要勾选确认；选择会保存在工程里（连同配置文件内容），重新打开工程或原配置文件不在了也能照样输出。合成时只转换一次，相框像素保持扫描原样。
- **文件被改动时**（FK-007）：
  - 导入扫描件时会计算整个文件的哈希。之后打开、识别、导出和最终输出前都会在后台核对；扫描件被换成别的文件或内容被改动时，扫描件列表显示“已改动”并说明原因，不会再用它输出。用“重新定位…”可以按内容找回原文件。
  - 读取过程中文件被改动，这次输出会被丢弃。
  - 调色文件关联后又被保存（例如又调了一次色）：画面、尺寸和色彩配置不变时照常使用并提示；换成了别的画面、尺寸或色彩配置变了时拒绝输出，提示重新关联。
  - 扫描件改名或移动后，只按内容（指纹）找回，不按文件名。
- 导出时的几何从**工程的导出记录**取得，调色文件旁边不需要 `.fk.json`。
- **本版重要限制**：
  - 导出后**未保存工程**就退出，导出记录会丢失；之后可以用“先选相片 → 新建对位”回导，但未保存的边框修改无法恢复（U008 增加崩溃恢复）。
  - 画面很平淡（雾、雪、大面积纯色）时，画面比对可能低于阈值，这时需要你手动确认。
- 蒙版：硬边缘 / 羽化 / 保留边缘（内缩）。默认硬边缘 0 px（U015 调整默认值）。
- 最终输出：真实扫描相框（默认，相框像素全部来自原扫描）或生成边框（PhotoFrame 风格的四边/等宽/画布比例）。

## 8. 后台任务

左栏“任务”列出正在进行和已结束的任务：排队中、进行中（百分比，可取消）、完成（用时）、失败（显示原因）、已取消、
**已过期未应用**。“已过期”表示任务运行期间你修改了它依赖的内容（例如重新识别时拖动了外框、合成预览时改了蒙版），
为保护你的修改，结果没有被应用；需要时重新执行即可。打开或新建工程会取消正在进行的任务，已经写完的导出文件会保留。

## 9. 工程

- 保存 Ctrl+S、另存为 Ctrl+Shift+S、打开 Ctrl+O、新建 Ctrl+N。工程文件使用相对路径，扫描件移动后可“重新定位”。
- 本版已知限制：新建/打开/拖入工程不提示保存当前工程（U008）；工程损坏时不提示可用备份 `.bak`（U008）。

## 11. 常见问题

- **“没有匹配的相片”**：在回导对话框的下拉框里选“指定为 …”，或在右栏“回导到这张相片…”（第 7 节）。
- **导出边缘有细白线**：见第 6 节限制；可在“编辑内框”（I）中把内框各边向内拖几个像素（1200 DPI 时约 5–10 像素）后再导出。
- **数量提示不消失**：修改数量后点“重新识别”。

## 12. 备份与恢复

本版：保存时上一版工程保存在同目录的 `<名称>.fkproj.bak`。工程损坏时可手动把 `.bak` 复制为新文件名后打开。显式恢复与崩溃恢复快照在 U008 实现。
