# RFCs and ADRs

- `NNNN-<module>.md` — one RFC per module or subsystem. Status: Draft → Accepted → Implemented (→ Superseded).
  An RFC is written and Accepted before the module's first line of code; it is revised in the same commit
  as any interface change.
- `ADR-NNNN-<decision>.md` — one Architecture Decision Record per significant, hard-to-reverse decision.
